# Library Management System – Setup Instructions

1. Install **Node.js** and **MySQL**, then import `database/library_management.sql` into MySQL.
2. Open the project in VS Code, navigate to `backend` using `cd backend`, and run `npm install`.
3. Create a `.env` file inside `backend` with your local MySQL credentials and JWT secret.
4. Start the backend using `npm run dev` and keep the terminal running.
5. Open `home.html` using **Live Server** in VS Code.
